# Ghost Shift — engine inventory (GS-00)

Ledger item GS-00 of [GHOST_SHIFT_ENGINE_INTEGRATION.md](GHOST_SHIFT_ENGINE_INTEGRATION.md): what the engine on
master already provides for each Ghost Shift design need, where it lives, and the concrete gaps. Written against
master `3182507` (October 2026). "Shipped player" means `player::Game` (`player/src/game.cpp`), the runtime that
`aether_player` and packaged games run. Ghost Shift itself is game-owned content in `games/GHOST-SHIFT`
(see its README); nothing here is an engine change.

## Summary

| Need | Reuse | Status for Ghost Shift |
|---|---|---|
| Host-and-join sessions, 1–4 players | `net/` session, host, replication, RPC | Works in-process and in `aether_server`; **not wired into `player::Game`** |
| Authority checks on tool requests | `RpcRouter` ownership + token bucket | Ownership/rate limit exist; reach/battery/residue validation is game code |
| Replicated contamination | `ReplicationServer`/`Client` on reflected `Field_Replicated` C++ components | **Luau state and attributes don't replicate** |
| Client movement prediction | `net/prediction.h` | Has its own kinematic model, separate from Jolt `CharacterMovement` |
| Physics props, tethers, doors | Jolt `PhysicsScene`, colliders, bodies | **No joint/constraint API** |
| Ghost AI | `ai/` BT, state tree, GOAP, utility, perception | Only perception (+ Nav) reaches the shipped player and Luau |
| Navigation | `nav/` Recast-style navmesh, dynamic, crowd | Player bake ignores Transform scale/rotation of box colliders |
| Spatial threat audio | `audio/` cues, spatial attenuation, listener | Usable now (Prankster moan) |
| Save | `save/` SaveGames slots, envelope, world state | Usable now (company slot) |
| Quests/abilities/attributes/inventory/interaction | gameplay, quests, inventory, interaction kits | Usable now from Luau |
| Editor authoring | `editor/` (+ Qt editor) | Scenes open/save; Ghost Shift content is generated by script for now |
| Packaging | cooker, `aether_cook`, `tools/ship` | Usable; Windows capture pending |

## Networking

- **Transport / connection:** `net/include/aether/net/socket.h` (`UdpSocket`, and `LoopbackNetwork` with seeded
  `LinkConditions` latency/jitter/loss/duplication for deterministic tests), `host.h` (`NetHost`: challenge
  handshake, SipHash-authenticated datagrams (`siphash.h`), per-address rate limits, timeouts, `Kind::Disconnect`),
  `connection.h` (reliable-ordered and unreliable channels).
- **Sessions:** `session.h` — `SessionHost`/`SessionClient` (password, build id, `max_players`, kicks, refusal
  reasons, signed `JoinToken`s with expiry), `LanBeacon`/`LanBrowser`/`LanLobbyService` (LAN broadcast discovery).
  Tests: `tests/test_net_session.cpp`, and the Ghost Shift prerequisites in `tests/test_net_production.cpp`
  (`NetProd_GhostShift_*`: only the owner changes shared state, a fifth player is refused, reconnect keeps
  ownership, host-owned prop transform converges under loss).
- **Replication:** `replication.h` — `NetIdentity` (net id, archetype, owner peer, `locally_owned`),
  `ReplicationServer` (snapshots of reflected fields marked `Field_Replicated`, relevancy/priority hooks, per-peer
  budget, `NetProfile`), `ReplicationClient` (`OnSpawn(archetype)`, `PredictLocally`, `ReadReplicated`).
  `interpolation.h` — `InterpolationBuffer` for remote entities.
- **RPC:** `rpc.h` — `RpcRouter` routes `Fn_Server`/`Fn_Client`/`Fn_Multicast` reflected methods; the server
  runs a server call only if the caller owns the entity (`RpcStats::rejected`), with a per-client token bucket
  (`calls_per_second`, `call_burst`, `throttled`). Luau can call them (`tests/test_net_rpc_script.cpp`).
- **Prediction:** `prediction.h` — `MovementServer`/`MovementClient` with `StepMovement` on `NetMovement`
  (a simple kinematic model: velocity, gravity, `ground_height`), `SanitizeInput`, reconciliation stats.
- **Dedicated server:** `tools/server` (`aether_server`, `aether_netclient`, `docs/manual/15-dedicated-server.md`):
  loads a cooked scene headless, replicates scene entities (archetype `scene`), spawns an `aether.player` pawn
  per player.

**Gaps**
1. **No listen server in `player::Game`.** `player/` doesn't link or create any `net::` object; the host-and-join
   model (one player hosts) needs the player to own a `NetHost` + `SessionHost` + `ReplicationServer` + `RpcRouter`
   (or embed `aether::server::DedicatedServer`) and clients a `SessionClient` + `ReplicationClient`. GS-01.
2. **Luau state doesn't replicate.** Script tables and `AttributeSet`s (`gas::AttributeSet` fields are not
   `Field_Replicated`) are local. Shared contamination, battery/tank, haunting and ghost state need replicated
   C++ components (game-owned, reflected) or a replicated attribute/component path that scripts can write. The
   Ghost Shift loopback test (`tests/test_ghost_shift.cpp`) therefore uses test-local `GsPatch`/`GsCleaner`
   components. GS-03.
3. **No relay / NAT traversal / internet lobby.** Discovery is LAN broadcast only; the manual records no
   cross-machine or NAT run. Needs the owner's relay/NAT service decision (integration doc approval checkpoint).
4. **Two movement models.** Networked prediction uses `net::StepMovement` (kinematic, flat `ground_height`),
   while the player walks with the Jolt `CharacterMovement` (`physics/include/aether/physics/character.h`).
   Predicting a Jolt character on clients requires either a deterministic replay of the Jolt character or
   adopting one model for both.
5. Game-level request validation (reach, battery/tank, remaining residue, request ids for late/duplicate RPCs)
   is not an engine feature; it is modelled game-side in the Ghost Shift loopback test.

## Physics (Jolt)

- `physics/include/aether/physics/physics_scene.h`, `physics_world.h`, `components.h`: `RigidBody`
  (Static/Kinematic/Dynamic, damping, gravity scale, CCD, rotation locks), `BoxCollider`/`SphereCollider`/
  `CapsuleCollider`/`ConvexCollider`/`MeshCollider` (triggers, friction, restitution), collision/trigger events
  to scripts (`OnCollisionBegin`/`OnTriggerEnter`…), Transform scale honoured through Jolt `ScaledShape`
  (`physics/src/physics_scene.cpp`). Queries from Luau: `Physics.Raycast`, `Physics.SphereCast`,
  `Physics.AddForce`/`AddImpulse`/`SetLinearVelocity` (`scripting/src/script_api.cpp`).
- `character.h`: `CharacterMovement` — the Jolt character controller (walk/run, slopes, steps, coyote time, jump
  buffer, root motion, pushing dynamic bodies). Ghost Shift's first-person body uses it.

**Gaps:** no joint/constraint API (hinges for doors, distance/spring constraints for the containment tether,
"grab" constraints for possessed furniture) — Jolt's constraints are not exposed by `PhysicsScene` or to scripts
(the only "constraint" in `physics_world.cpp` is Jolt's contact-constraint capacity). Host-owned physics outcomes
for GS-04 need either constraints or kinematic scripted motion replicated as Transform.

## AI and navigation

- `ai/include/aether/ai/behavior_tree.h`, `bt_runtime.h`, `bt_world.h`, `state_tree.h`, `goap.h`, `utility.h`,
  `blackboard.h`: decision systems with editor widgets (`editor/qt/behavior_tree_editor_widget.*`, AI debugger).
- `perception.h`: `PerceptionWorld` (sight/hearing stimuli, `AIPerception`/`AIStimuliSource` components).
- **In the shipped player:** only perception runs — `Game::StartRuntime` creates a `PerceptionWorld` with box
  line of sight, and Luau gets `AI.CanSee`, `AI.GetKnown`, `AI.GetTarget`, `AI.IsSightReady`, `AI.SetDebugState`
  (`scripting/src/ai_api.cpp`). Behavior trees, state trees, GOAP and utility AI are **not** ticked by
  `player::Game` and have no Luau API, so game AI in a shipped build is script code. The Prankster is therefore a
  seeded Luau state machine on the fixed step (`games/GHOST-SHIFT/Content/Scripts/Prankster.luau`).
- `nav/include/aether/nav/navmesh.h`, `dynamic.h`, `crowd.h`, `hierarchical.h`, `components.h`; Luau `Nav.FindPath`,
  `Nav.MoveTowards`, `Nav.IsReady`.

**Gaps**
1. The player's navmesh bake (`BakeSceneNavigation`, `player/src/game.cpp`) adds every static `BoxCollider` as
   `AddBox(t.position + box.center, box.half_extents)`: **Transform scale and rotation are ignored** (as is the
   collider hierarchy). `BoxLineOfSight` (AI sight) does the same. Physics does honour scale, so a scaled or
   rotated box collides differently from how it navigates/occludes. Willow House keeps every collider unscaled
   and axis-aligned (visual meshes are separate, scaled entities) to stay consistent.
2. No BT/state-tree runtime or Luau binding in the shipped player (see above).

## Audio

`audio/include/aether/audio/audio_system.h` (`AudioSource` Play/Stop/Fade/SetCue, `AudioListener`, reverb zones),
`cue.h`/`cue_player.h` (`.acue` graphs), `spatial.h` (attenuation models, min/max distance, spatial blend,
doppler), `mixer.h` (buses). A spatial cue follows its entity — the Prankster's warning moan is a spatial
`AudioSource` on the ghost. Gaps: occlusion is a cue flag only; no subtitles for threat cues yet (GS-08).

## Save

`save/include/aether/save/save_games.h` (`SaveGames` slots — Luau `SaveGames.CreateSaveObject/SetNumber/
SaveToSlot/LoadFromSlot/DoesSaveExist/DeleteSave`, `scripting/src/save_api.cpp`), `envelope.h` (checksummed
envelope), `world_state.h` (`CaptureWorld`/`RestoreWorld`), `settings.h`. Per-user folders come from
`player::ResolveUserPaths` (`player/include/aether/player/user_paths.h`). Ghost Shift's company save is the
`"company"` slot. Gap: per-player reward validation across a network session (GS-07) is game work; the save
is per machine.

## Gameplay kits

- Attributes/effects/abilities: `gameplay/include/aether/gameplay/` — `.aeffect` (instant/timed/infinite
  modifiers), `.aability` (cost + cooldown effects, tag gating; `AbilitySystem::Affordable` refuses a cost that
  would take an attribute below its minimum). Luau `Attributes.*`, `Effects.*`, `Abilities.*`
  (`scripting/src/gameplay_api.cpp`).
- Quests: `quests/` — `.aquest` with count/tag/flag objectives, optional objectives, prerequisites and
  `"rewards": {"effects": [...], "items": [...]}`. **Unknown keys are silently ignored**, so a misspelled rewards
  block pays nothing. `QuestSystem` completes a quest once (`Result::AlreadyCompleted`) and applies reward effects
  on completion. Luau `Quests.*`; script events `OnQuestCompleted` etc. (`player/src/game_kits.cpp`).
- Inventory: `inventory/` — `.aitem` (stacks, weight, equip slot, use effect). Luau `Inventory.*`; events
  `OnItemAdded`/`OnItemRemoved`…
- Interaction: `interaction/` — `Interactable` (prompt, range, required/blocked tags), Luau `Interaction.*`.
  Ghost Shift's first playable uses its own distance checks; adopting `Interactable` for prompts is a GS-06/08
  follow-up.

## Editor

`editor/src` (scene editing, content browser, save/reopen) and the Qt editor in `editor/qt` (behind
`AETHER_BUILD_QT_EDITOR`): scene, script component, physics, navigation, behavior tree, animation, material and
Blueprint widgets, play-in-editor (`editor_play_runtime.*`). The MCP server (`mcp/`, used to build
STARDUST-HOP) can author content too. Gap for GS-09: no reusable Ghost Shift data types (rooms, ghost anchors,
contamination, tool stations) — Willow House is generated by `games/GHOST-SHIFT/tools/build_content.py` with tags.

## Packaging

Cooker (`cook/`, `tools/cook` → `aether_cook --strict`), `.apak` archives (`tools/pak`), `tools/ship`
(`aether_ship.py`, release assembly), the player's `--pak/--headless/--frames/--report/--user-dir` flags
(`player/main.cpp`). `--report` prints a fixed engine list of `Player` attributes; Ghost Shift prints its own
attributes from `GhostShift.luau`'s `OnDestroy` at the end of the run instead of changing the player. Windows
packaged capture for Ghost Shift is not done yet (GS-08).
