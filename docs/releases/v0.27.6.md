# Aether Engine v0.27.6 — Qt editor startup fix

This prerelease corrects the Windows D3D12 viewport initialization for the Qt
editor and makes the Qt application the default Windows build output. It
continues the v0.27.5 editor migration.

## Windows editor

- `AetherEditor.exe` is the Qt 6 world editor; the ImGui editor remains
  available as `AetherEditorLegacy.exe`.
- The D3D12 render pipeline now initializes its default blend state with valid
  API values. Previously the viewport could fail to create its first pipeline
  on startup.
- The Qt editor opens the world viewport and renders its default scene on the
  local NVIDIA RTX 3050 development machine.

The Qt host remains Windows/D3D12 only, and the editor migration is incomplete.
Use the legacy editor for workflows not yet available in the Qt host. The
standalone AETHER-01 proof game and engine packages remain available through
the Windows release artifacts.
