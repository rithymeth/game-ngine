# Aether Engine v0.27.5 — current editor in the Windows package

This pre-1.0 prerelease carries forward the v0.27.4 engine hardening and makes
the current Qt editor the default application in the Windows editor package.

## Editor package

- `AetherEditor.exe` is the Qt 6 Windows/D3D12 editor UI, with its Qt runtime
  libraries and platform plugins included in the package.
- `AetherEditorLegacy.exe` keeps the established ImGui editor available for
  tools that have not migrated to the Qt host.
- The Qt editor loads the AETHER-01 project, its 41-entity startup scene, and
  its imported glTF models, and supports Play-in-Editor. Its migration remains
  in progress; it does not yet replace every legacy editor tool.

The Windows CI job runs the Qt editor self-test and validates the packaged
AETHER-01 proof game. The existing Linux, macOS, Windows, physics, sanitizer,
fuzz and regression checks remain release gates.

## Downloads and limits

`AetherEditor-windows-x64.zip` contains both editors, the cooker, pak tool,
player, manuals, generated API reference, engine assets and plugins. Launch
`AetherEditor.exe` for the current UI; see `EDITOR_README.txt` for the legacy
fallback. The separate `AETHER-01-windows-x64.zip` contains the standalone
proof game.

The Qt host is currently Windows/D3D12 only and remains a staged editor
migration. Use the legacy editor for workflows that are not yet available in
the Qt host. Downloadable binaries are unsigned Windows x64 Release builds
that require an AVX2-capable CPU, D3D12 and the Microsoft Visual C++ v14 x64
runtime. See the bundled `WINDOWS_REQUIREMENTS.md`.

AETHER-01 remains a greybox proof with temporary art and synthesized sound,
not the polished 15–30 minute slice, 60–90 minute MVP or full five-act game.
The player does not render lighting or skeletal animation; no target-hardware
1080p/60 FPS claim is made. The broader M8 and Aether 1.0 production gates
remain open.
