# Aether Engine v0.27.0 — AETHER-01 proof release

This pre-1.0 release improves the existing engine workflow and ships
**AETHER-01: First Contact**, a short, playable greybox proof game.

## Engine improvements

- Standalone cooked scenes render static glTF models, textures and runtime HUD
  through the existing RHI.
- The Third Person template uses the existing character physics controller.
- Cooked audio, cues, mixer settings and sequence audio work in the player.
- Scene replacement rebuilds runtime system bindings and tears down sequences
  safely while preserving custom scheduler systems.
- Pause preserves menu input while stopping simulation and mission time.
- Windows packages include notices, checksums and a commit inventory.
- Project version stamps now match the published engine version, 0.27.0.

## Playable proof

Retrieve the AEGIS Rifle, defeat the Scout, clear the shielded Sentinel and
charging Hunter, defeat the four-phase Warden, then access the archive reveal.
ARC Pistol and VOLT Shotgun provide distinct shield/range/damage behavior.
Milestone checkpoints, death/restart, a HUD, synthetic sound cues, a short
camera/text/audio sequence, pause and volume settings are included.

Extract `AETHER-01-windows-x64.zip` and run `AETHER-01.exe`. Controls and build
instructions are in its README. Extract `AetherEditor-windows-x64.zip` for the
editor, cooker, pak tool, player and manuals.

## Release checks

Required CI builds/tests cover Windows MSVC, Linux GCC/Clang/ASan/UBSan/physics,
and macOS Apple Silicon. The Windows game package is extracted and checksummed,
then launched from an empty working directory with its source moved away.
Startup and pause pixels are checked. An input trace from the cooked-game
regression is replayed through the extracted executable, headless and rendered,
with a live player and completed archive ending required in the final report.
Scene save/close/reopen compares all serialized component data.

`RELEASE_MANIFEST.json` identifies the exact build commit and artifact hashes;
`SHA256SUMS.txt` verifies the two ZIP files. The release workflow's artifacts
also contain captures, the input trace and playthrough logs.

## Supported build and limitations

The downloadable binaries are **unsigned Windows x64 Release builds**, using
D3D12 and AVX2-capable CPUs. Windows CI uses WARP where hardware graphics are
unavailable. Vulkan is verified locally but is disabled in the hosted Windows
release build. Linux/macOS checks establish source builds; no binary packages
for those platforms are included in this release.

The binaries require the Microsoft Visual C++ v14 x64 runtime. See the bundled
`WINDOWS_REQUIREMENTS.md` for the official installer and startup instructions.

The proof is a brief greybox with temporary cube/checker art and synthesized
sounds. It does not meet the GDD's aspirational 60–90 minute MVP or full five-act
3–5 hour game. Lighting and skeletal animation are not rendered by this player;
there is no voice acting or finished cinematic/art quality. Camera obstruction
and game hitscan cover this level's unrotated box colliders. Checkpoints preserve
milestones, with fresh health/ammo and reset unfinished encounters. Ammo reserves
are unlimited. Settings expose volume, not graphics quality. No target-hardware
1080p/60 FPS claim is made. Broader Aether 1.0 production gates remain open.
