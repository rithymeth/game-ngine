# Aether Engine v0.27.3 — editor data safety and readiness

This pre-1.0 proof release continues improving existing engine workflows and
includes the AETHER-01: First Contact greybox game. It supersedes v0.27.2.

## Improvements since v0.27.2

- The Qt editor registers schemas for audio, gameplay attributes, sequences
  and physics components. It starts the selected project modules before
  opening scenes and refuses to open a scene when a required factory is not
  available, preventing partial scene saves.
- Strict editor scene loads report unknown components as errors. Generic
  runtime loading retains its existing behavior. Scene round-trip checks cover
  component data preservation, and legacy entities receive readable names
  from their tags or model names.
- The AETHER-01 engine readiness matrix maps all 112 GDD sections to current
  engine support, proof evidence and deferred production work.
- Windows CI builds the optional Qt editor and runs its self-test alongside
  the engine, AETHER-01 cook, launch, render and standalone package checks.
- Quest JSON parsing reports invalid types for objective and reward fields
  instead of throwing. The advisory fuzzer's malformed-quest reproducer is
  retained in the regression corpus.

No new engine feature family or serialized package format is introduced by
this increment. `PackageManifest` remains version 1 with CRC-32.

## Downloads and checks

Extract `AETHER-01-windows-x64.zip` and run `AETHER-01.exe`. Its README lists
controls. `AetherEditor-windows-x64.zip` contains the production editor, cooker,
pak tool, player, manuals and built-in plugin catalog.

The release requires the Windows MSVC, Linux GCC/Clang/physics/ASan/UBSan and
macOS Apple Silicon CI lanes. Windows checks the editor and game packages,
verifies checksums, reproduces the game archive using the packaged cooker,
then completes headless and rendered playthroughs through the archive ending.
`RELEASE_MANIFEST.json` records the build commit and SHA-256 hashes;
`SHA256SUMS.txt` covers both primary ZIPs.

## Supported builds and limitations

Downloadable binaries are unsigned Windows x64 Release builds with D3D12,
an AVX2-capable CPU and the Microsoft Visual C++ v14 x64 runtime required.
See bundled `WINDOWS_REQUIREMENTS.md`. Linux/macOS CI verifies source builds;
this release provides no binary package for those platforms.

AETHER-01 is a short greybox proof with temporary art and synthesized sound,
not the polished 15–30 minute slice, 60–90 minute MVP or full five-act game.
The player does not render lighting or skeletal animation; no target-hardware
1080p/60 FPS claim is made. The broader M8 and Aether 1.0 production gates
remain open.

CRC-32 detects accidental damage, not authenticity. Verification covers listed
files and does not lock out concurrent modification. Concurrent updates to one
package folder are unsupported. If rollback itself fails, the error identifies
the retained backup folder. Process crashes/power loss during publication are
not covered by the recoverable-error rollback contract. Full incremental
dependent-asset cooking, signed releases and clean-machine upgrade/rollback
studies remain outstanding.
