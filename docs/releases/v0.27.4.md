# Aether Engine v0.27.4 — release and cook reliability

This pre-1.0 prerelease hardens the existing engine build and packaging
workflows. It supersedes v0.27.3.

## Improvements since v0.27.3

- Linux, macOS and Windows CI now run the registered regression suite alongside
  the existing unit and functional tests.
- Linux GCC and Windows require the module dependency graph check, which verifies
  module layers and rejects dependency cycles.
- Windows CI repeats the AETHER-01 Development cook and checks that the archive
  and manifest are byte-identical, then verifies incremental texture-cache reuse.
- AETHER-01 cook proof is reused once per test process, reducing repeated test
  setup without changing the cooked project.
- Release evidence records deterministic cook hashes and cache hits.

No new engine feature family or serialized package format is introduced by this
increment. `PackageManifest` remains version 1 with CRC-32.

## Downloads and checks

Extract `AETHER-01-windows-x64.zip` and run `AETHER-01.exe`. Its README lists
controls. `AetherEditor-windows-x64.zip` contains the editor, cooker, pak tool,
player, manuals and generated API reference.

The release requires Windows MSVC, Linux GCC/Clang/physics/ASan/UBSan and macOS
Apple Silicon CI. Windows checks the editor and game packages, verifies their
checksums, reproduces the game archive using the packaged cooker, then completes
headless and rendered playthroughs through the archive ending.
`RELEASE_MANIFEST.json` records the build commit and SHA-256 hashes;
`SHA256SUMS.txt` covers both primary ZIPs.

## Supported builds and limitations

Downloadable binaries are unsigned Windows x64 Release builds with D3D12,
an AVX2-capable CPU and the Microsoft Visual C++ v14 x64 runtime required.
See bundled `WINDOWS_REQUIREMENTS.md`. Linux/macOS CI verifies source builds;
this release provides no binary package for those platforms.

AETHER-01 is a short greybox proof with temporary art and synthesized sound,
not the polished 15–30 minute slice, 60–90 minute MVP or full five-act game.
The player does not render lighting or skeletal animation; no target-hardware
1080p/60 FPS claim is made. The broader M8 and Aether 1.0 production gates
remain open.

CRC-32 detects accidental damage, not authenticity. Verification covers listed
files and does not lock out concurrent modification. Concurrent updates to one
package folder are unsupported. If rollback itself fails, the error identifies
the retained backup folder. Process crashes/power loss during publication are
not covered by the recoverable-error rollback contract. Full incremental
dependent-asset cooking, signed releases and clean-machine upgrade/rollback
studies remain outstanding.
