# 2026-11-16

Four plant generators in `engine/include/aether/assets/procedural_mesh.h`: `GenerateShrub` (leaf masses on thin stems), `GenerateGrass` (two-sided tapering
ribbons, flat shaded), `GenerateReeds` (stalks with cattail heads) and `GenerateCactus` (a column with a rounded top and up to four arms), as kinds Shrub, Grass,
Reeds and Cactus for `GenerateVariant`. The Procedural World editor's starter rules now all have a mesh family (the user's own added rules still start with none),
so the shrub, grass, reed and cactus rules bake instead of baking as nothing.

A bake's object budget used to be spread evenly over every instance, which with a grass rule of 40 tufts per 100 square metres would have thinned the trees by
the same factor as the grass. It follows the scatter's pecking order now: earlier rules (trees) keep every instance while there is room, and the grass is
thinned to what is left. A test holds it (all pines survive a budget that grass would have eaten).

Checked in the player: a gallery of every plant up close (shrubs, grass tufts, reeds and cacti read correctly), and a re-baked Temperate world with 3,000 objects.
The tufts are about 0.5 m, so they only show up close; that is the scale of grass.

Not done: a flower or bush variant with colour, grass that sways (no wind in the shader), LODs or impostors for the 3,000-object scenes (one draw call each),
and a grass card with a texture (the generator has no textures).
