# 2026-11-23

A global wind, `Wind`, a scene component (renderer/components.h, with the lights): `direction_degrees` (0 toward +X, 90 toward +Z), `strength` (0 calm to 4 a gale, a multiplier on
every material's sway), `gust_speed` and `gustiness` (the share of the sway that is the slow, uneven swell that varies along an object). The first Wind in the world is used; a
world without one has the breeze it had before, 27 degrees at strength 1. It is in the frame constants (`wind`, `wind_gusts`; 1232 to 1264 bytes) with its values clamped and
not-a-number replaced by the defaults.

The vertex shader reads it. The wind blows in the world, but a sway is added to a position in the object's own space, so the world direction goes through the inverse of the model's
linear part (the stored normal matrix is its inverse transpose, so the inverse is that transposed). A side effect, and a better one: it also divides out the object's scale, so the
sway is in world metres however big the model is made (before, a tuft at scale 2 swayed twice as far, because the sway was in local units). The direction is now a unit vector
(it was (1, 0.5), 1.12 long), so the default breeze is about 10 percent gentler than it was.

Checked: CPU tests for the component (defaults, the first one used, clamps and NaN, the scene file round trip, the layout against the HLSL), and a GPU test that the wind is a world direction:
a tuft turned half way round sways the same way on screen as one that is not (42 and 38 px against a background render without grass), a wind toward the camera moves it under 1 px
sideways. A negative control: with the world-to-local conversion removed the turned tuft sways -87 px (the mirror) and the test fails.

Not done: no wind zones (one global wind; an area with its own wind, or a wind that falls off, would be a volume); the shadows still do not sway; no wind on the editor's panels (the component
is editable like any other, but the Procedural World bake does not add one, so baked worlds have the default breeze); particles and cloth do not read it.
